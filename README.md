# 📱 برنامج ملاحظات المدير — المدرسة القرآنية الوقفية

برنامج لإضافة ملاحظات وتقييمات المدير على المدرسة، يعمل على الهاتف مع تخزين محلي كامل.

## ✨ المميزات
- شاشة دخول آمنة للمدير (المستخدم: `admin` / كلمة السر: `1234`)
- إدارة بيانات المدرسة (الاسم والموقع)
- إدارة المدرسين (الاسم، الصف، عدد الطلبة)
- تقييم شامل: تقييم المعلم، الدفاتر، نظافة الفصل، ترتيب السبورة، الأنشطة، الانضباط الصفي، التعاون مع الكادر، التعاون مع أولياء الأمور
- معايير التقييم قابلة للإضافة والتعديل
- أنواع زيارات قابلة للتخصيص
- تقارير صفية مع ملاحظات عامة لكل زيارة
- إرسال التقرير عبر واتساب بضغطة واحدة
- حفظ التقارير حسب التاريخ والرجوع إليها في أي وقت
- الشعار واسم المدرسة يظهران في الشاشات والتقارير
- يعمل بدون إنترنت (PWA) ويمكن تثبيته على شاشة الهاتف

## 🚀 كيفية النشر على GitHub (مجاناً)

1. أنشئ حساباً على [github.com](https://github.com)
2. اضغط **New repository** وسمّه مثلاً `qes-manager`
3. ارفع كل ملفات هذا المجلد (index.html, manifest.json, sw.js, الأيقونات)
4. من إعدادات المستودع: **Settings → Pages**
5. اختر الفرع `main` والمجلد `/root` ثم **Save**
6. بعد دقيقة سيظهر رابط مثل: `https://username.github.io/qes-manager/`

## 📲 التثبيت على الهاتف
1. افتح الرابط من متصفح الهاتف (Chrome / Safari)
2. من قائمة المتصفح اختر **إضافة إلى الشاشة الرئيسية**
3. سيظهر التطبيق بأيقونته الزرقاء (الشعار + «برنامج المدير») ويعمل كتطبيق مستقل

## 🎨 أيقونة أوضح (اختياري)
الأيقونة تعمل تلقائياً. وإن أردت نسخة PNG بالنص العربي «برنامج المدير» بأعلى دقة لأجهزة آيفون:
افتح ملف `make-icons.html` من المتصفح واضغط زر التنزيل، ثم ضع الملفين `icon-192.png` و`icon-512.png` بجانب باقي الملفات على GitHub.

## ⭐ خيارات التقييم جاهزة
كل بنود التقييم تأتي بخياراتها الافتراضية جاهزة عند أول تشغيل على أي جهاز (مثل: ترتيب السبورة → مرتبة / مقبولة / غير مرتبة)، ويمكن لأي مدير تعديلها أو إضافة خيارات من شاشة «معايير التقييم».
